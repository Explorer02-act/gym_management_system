# MUSCLE MONSTERZ Architecture Roadmap

## Phase 1 - Business Foundation

Implemented:
- Membership plans stored in database
- Gym settings with QR/payment configuration
- Payment records
- Single-step enrollment API
- Dashboard revenue from payments
- Audit timestamps on core entities
- Admin entity scaffold for future JWT login
- PDF receipt download for payment records

## Phase 2 - Member Operations

Implemented:
- Member profile DTO/API
- Current membership summary per member
- Membership history
- Attendance history
- Total visits
- Revenue generated by member
- Photo URL update endpoint
- Frontend profile preview from member cards

## Phase 3 - Expiry and Renewal Engine

Implemented:
- Expiring today API
- Expiring in 3 days API
- Expiring in 7 days API
- Grouped expiring members API
- WhatsApp renewal message links
- Frontend renewal links in the risk queue

Next:
- Renewal from plan card with payment capture
- Dedicated renewal receipt flow

## Phase 4 - Frontend Evolution

Current frontend:
- Spring Boot static owner console
- Dashboard metrics
- Enrollment with plan cards and QR payment
- Member search/cards/profile preview
- Recent check-ins
- Expiring queue with WhatsApp action
- Revenue summary and revenue by plan
- Attendance leaderboard

Planned React frontend pages:
- Dashboard
- Members
- Member Profile
- Enrollment
- Check-In
- Billing
- Settings
