# MUSCLE MONSTERZ Architecture Roadmap

## Phase 1 - Business Foundation

Implemented first:
- Membership plans stored in database
- Gym settings with QR/payment configuration
- Payment records
- Single-step enrollment API
- Dashboard revenue from payments
- Audit timestamps on core entities
- Admin entity scaffold for future JWT login

## Phase 2 - Member Operations

Next:
- Member profile DTO/API
- Current membership summary per member
- Membership history
- Attendance history
- Total visits
- Revenue generated by member
- Photo URL upload/update endpoint

## Phase 3 - Expiry and Renewal Engine

Next:
- Expiring today API
- Expiring in 3 days API
- Expiring in 7 days API
- WhatsApp renewal message links
- Renewal from plan card
- Renewal payment records

## Phase 4 - React Frontend

Frontend pages:
- Dashboard
- Members
- Member Profile
- Enrollment
